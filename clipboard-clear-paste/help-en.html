1. What this program does

Clipboard Clear Paste strips formatting from the clipboard at the moment you paste. You copy a chunk of a web page, a Word document or an AI chat answer, and what lands in your document is clean content - no foreign fonts, background colours, borders, citation markers or invisible junk that wrecks your layout later.

The program has no main window. Once running it sits in the notification area next to the clock and waits for one of three hotkeys. It uses no noticeable CPU and never connects to the internet.

Why not just use "paste as plain text"? Windows and Word can paste text only, but then you lose everything - headings, lists, bold, tables. Clipboard Clear Paste keeps the document structure and removes only the visual layer.

2. Getting started

After launch a blue clipboard icon appears in the notification area. If you cannot see it, click the up arrow next to the clock - Windows hides new icons by default. You can drag it onto the permanent bar from there.

The program is ready immediately. Two options are enabled by default: Deep HTML cleanup and Render Markdown when pasting; the rest are off. Your settings are remembered between sessions.

3. The three hotkeys

The hotkeys work globally, in any application, with no need to switch to the program first.

Ctrl + Shift + V - paste cleaned HTML

The main mode. Keeps the document structure and removes the entire visual layer: style attributes, <font> tags, CSS classes, comments, scripts and the leftovers Microsoft Word generates.

Before
<p style="color:red;font-family:Calibri"
class="MsoNormal"><font size="4">
Result <b>positive</b></font></p>
After
<p>Result <b>positive</b></p>

Tags that survive: paragraphs, headings h1-h6, lists, bold, italic, underline, strikethrough, tables, images, block quotes, code, horizontal rules and subscript and superscript. Everything else is removed, but the text inside removed tags is kept.

Chemical formulas and units are safe. H2SO4 will not turn into H2SO4, nor m2 into m2. The indices carry over to the plain-text version too, as H₂SO₄ and m².

Works with Google Docs and Notion. Those editors do not store bold as a tag but as a CSS style. The program recognises this and converts it into real bold before stripping the styles, so your formatting survives.

Tables come out with borders. Cleaning removes every style, so a table would otherwise land in your document without a single line. The program adds one thin line around each cell to keep it readable. You can turn this off with the Add borders to tables menu option.

Tables paste into Excel as columns. In the plain-text version cells are separated by tabs, so spreadsheets split them correctly. Empty cells keep their position.

It works the other way round too. When the clipboard holds raw Markdown - copied from a ChatGPT, Claude or Gemini answer, from a .md file or from Obsidian - the same hotkey pastes it into Word or Outlook as ready formatted text. Headings, lists, tables, bold and working links instead of bare ## and **.

Notepad and code editors still receive the Markdown untouched - every application gets what it expects.

Tables come with borders - a single line around every cell. Markdown carries no appearance information, so without this a table would look like columns of loose text in Word.

Alt + Shift + V - paste as plain text

Removes formatting completely. What remains is bare text with no headings, lists or bold. Useful for form fields, code editors, terminals and anywhere formatting only gets in the way.

Alt + Shift + M - paste as Markdown

Converts formatting into Markdown syntax. This is the richest mode - it carries across elements that ordinary pasting cannot.

Particularly useful when working with AI tools. ChatGPT, Claude, Gemini and Perplexity handle Markdown better than any other format - they see the structure of a document instead of a wall of text. Select a passage from an article or report, press Alt+Shift+M and paste it into the chat window complete with headings, lists and tables.

Together with the rendering described above this closes the loop both ways: document → Markdown → AI tool, then the AI answer → formatted text → Word.

HTML elementMarkdown output
Headings h1-h6# through ######
Bold**text**
Italic*text*
Strikethrough~~text~~
Link[text](url)
Image![alt](url)
Bulleted list- item

Underline disappears because Markdown has no syntax for it - the text remains. Code blocks are protected: their contents are not processed, so asterisks and underscores inside code stay untouched.

4. Cleanup options

The switches in the tray menu decide what else gets removed and how the program treats Markdown. They apply to all three paste modes.

Deep HTML cleanup (on by default)

The most important option. Keeps only content tags and strips every attribute from them. Without it the program removes just styles and fonts, leaving the rest of the HTML structure intact. Turn it off if you need to preserve the original markup.

Remove links <a>

Removes hyperlinks together with their text. For example "See here for details" becomes "See for details". Stray spaces before punctuation are cleaned up automatically.

Remove square brackets [...]

Deletes anything in square brackets along with a preceding comma. Meant for text with citation markers such as [1] or [2, 3]. Note that it will also remove square brackets that are part of the content.

Remove tables

Turns a table into plain text - cells separated by spaces, each row on its own line. The cell contents themselves are preserved.

Before
| Sample | Result |
| A-1 | OK |
After
Sample Result
A-1 OK

Remove images <img>

Off by default, meaning images are kept. In Markdown mode an image becomes ![alt](url). Turn this on when pasting somewhere images are unwanted.

Render Markdown when pasting (on by default)

Controls whether raw Markdown from the clipboard reaches rich editors as formatted text. The program only recognises notation that leaves no room for doubt: headings, tables with a separator row, code blocks, bold, links and block quotes.

Lists need at least two items. A single line starting with a dash is far more often a sentence than a list, so it stays as text. Ordinary prose is safe - things like range 3-5 days, 5 EUR * each or my_file_name are left alone.

If the program recognises no construct at all, it does not interfere - it performs an ordinary paste.

Append source address

Off by default. When enabled, the address of the page the content came from is added below the pasted text. The program reads it from data the browser itself places on the clipboard - nothing is requested or sent.

Useful when working with source material: you paste a passage and its origin is recorded straight away. Works in all three modes. If you copied from a program that supplies no address (Word, for example), nothing is appended.

Always-on cleanup

Regardless of your settings, the program always removes HTML comments, scripts, stylesheets, Microsoft Office markup and citation markers from Perplexity and Google NotebookLM - those circled numbers that clutter pasted text.

6. Changing the hotkeys

Ctrl+Shift+V is already taken by some programs, Visual Studio Code and Slack among them. A global hotkey overrides them, so you may need to change it.

The easy way: tray menu › Help › Open settings file. It opens in your default editor and the top of the file carries a short set of instructions - no need to come back here.

The file is created automatically the first time the program runs and lives in %LOCALAPPDATA%\ClipboardClearPaste\settings.json. Close the program, change one of the three values and start it again:

"hotkey_smart": "ctrl+shift+V",
"hotkey_plain": "alt+shift+V",
"hotkey_markdown": "alt+shift+M"

Save the file and start the program again.

How to write a hotkey

Separate modifiers and the key with +. Case does not matter. A hotkey must contain at least one modifier, otherwise it would intercept ordinary typing.

ElementAccepted values
Modifiersctrl, alt, shift, win
Letters and digitsA-Z, 0-9
Function keysF1 to F12
Numeric keypadNUMPAD0 to NUMPAD9
Named keysSPACE, ENTER, TAB, BACKSPACE, ESC, INSERT, DELETE, HOME, END, PGUP, PGDN, LEFT, UP, RIGHT, DOWN
Punctuation; = , - . / [ ] \ ' and backtick

Valid examples: ctrl+alt+V, win+shift+V, ctrl+shift+F9, ctrl+alt+INSERT.

If you enter something the program does not understand, you will see a message at startup and that hotkey reverts to its factory value. A mistake in the file can never prevent the program from starting.

7. Interface language

By default the program follows your Windows display language. You can change it in the Language menu. Included: English, Polish, German, French, Spanish, Italian, Japanese and Chinese.

The cleaning engine itself is independent of the content language. It correctly handles Latin, Cyrillic, Greek, Chinese, Japanese, Korean, Arabic, Hebrew, Thai and Devanagari scripts, as well as emoji. It makes no difference what language you copy.

8. Behaviour that surprises people

Ctrl+Shift+V works everywhere.

The program puts two versions on the clipboard at once: formatted and plain. Each application takes the one it understands - Outlook, Thunderbird and Word take the formatting along with images, while Notepad, code editors and terminals get clean text. You never have to think about which hotkey to use.

Links stop being clickable even with default settings.

With deep cleanup enabled a hyperlink becomes ordinary text - the label stays but is no longer clickable. The Remove links option goes further and deletes the label too. To keep working links, either turn off deep cleanup or use Markdown mode, which writes the address out explicitly as [text](url).

Images on the clipboard are not restored.

The program puts your previous clipboard contents back afterwards, but bitmaps are skipped. If you had an image on the clipboard it will be lost. Text and HTML are restored normally.

9. Troubleshooting

A hotkey does not work

Usually another application has claimed it - global hotkeys are exclusive, so only one program can own a given combination. When this happens you get a message at startup naming the conflicting hotkey. Either close the other application or rebind its keys.

Also check that the hotkeys are not paused - the Pause hotkeys menu item would show a tick.

Nothing was pasted

If you used Ctrl+Shift+V, check whether the target application accepts formatted text at all (see section 7). If the clipboard held no HTML, the program performs an ordinary paste instead.

The icon disappeared from the taskbar

Click the up arrow next to the clock - Windows moves less-used icons there. You can drag it back onto the permanent bar.

Restoring default settings

Close the program and delete %LOCALAPPDATA%\ClipboardClearPaste\settings.json. Factory values return on the next start.

Citation markers are not removed

The program recognises Perplexity and NotebookLM citations by their CSS class names, which works in any language. An additional rule based on accessibility labels recognises English and Polish keywords. If you use those tools with a different interface language, some markers may remain - the Remove square brackets option helps in that case.

10. Privacy and data

The program runs entirely on your computer.

  • No internet access. It makes no network connections whatsoever.
  • Clipboard contents are never saved. Text is processed in memory and pasted immediately.
  • No telemetry or usage statistics are collected.
  • No keyboard monitoring. Windows notifies the program only about the three registered key combinations; no other keystroke is visible to it.

The only file written is your settings: %LOCALAPPDATA%\ClipboardClearPaste\settings.json. It contains the state of the switches and your chosen language - nothing else.
