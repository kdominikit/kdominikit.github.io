Clipboard Clear Paste

Paste text without the mess. Windows tray utility.

Copy something from a web page, a Word document or an AI chat, paste it into your document, and suddenly the fonts are wrong, the background is grey, and there are little citation numbers everywhere. Cleaning that up by hand takes longer than writing the text did.

Clipboard Clear Paste fixes it at the moment you paste. Press Ctrl+Shift+V instead of Ctrl+V. Your headings, lists, bold text and tables survive. Fonts, colours, borders, CSS classes, Microsoft Office leftovers and citation markers do not.

Three ways to paste

ShortcutWhat it does
Ctrl+Shift+V Pastes cleaned rich text - structure kept, visual layer removed. Also renders raw Markdown into formatted text.
Alt+Shift+V Pastes as plain text. Nothing but the words.
Alt+Shift+M Pastes as Markdown - headings, lists, tables, links and code blocks in Markdown syntax.

A two-way bridge between AI tools and your documents

The Markdown conversion runs in both directions, and that is where this tool stands apart from single-purpose converters.

  • Document to AI: Alt+Shift+M turns any selection into clean Markdown, ready to drop into a ChatGPT, Claude or Gemini chat window.
  • AI back to document: paste an answer with Ctrl+Shift+V and the raw Markdown arrives in Word or Outlook as finished formatted text - headings, lists, bordered tables, bold and working links instead of bare ## and ** clutter.

Plain-text targets are unaffected. Notepad, VS Code and terminals still receive the Markdown exactly as it was, character for character.

Built for technical writing

Chemical formulas and units survive

H₂SO₄ stays H₂SO₄ and m² stays m², in the formatted paste and in the plain-text one. Most cleanup tools flatten subscripts and superscripts.

Tables paste into Excel as real columns

Cells are separated by tabs, so spreadsheets split them correctly instead of dumping everything into one cell. Empty cells keep their position.

Google Docs and Notion keep their formatting

Those editors store bold as a CSS style rather than a tag, which is why most cleaners silently lose it. This one converts the style into real bold before stripping anything.

Works in any language

The cleaning engine is independent of the language of the content. Latin, Cyrillic, Greek, Chinese, Japanese, Korean, Arabic, Hebrew, Thai, Devanagari and emoji are all handled correctly. The interface itself is available in eight languages.

Built to be trustworthy

No internet accessNo network connections of any kind. Not for updates, not for telemetry, not for anything.
No clipboard loggingText is processed in memory and pasted immediately. Nothing is written to disk.
No keyboard monitoringMany hotkey tools install a low-level keyboard hook - the same technique keyloggers use. This one does not.
No third-party librariesOne self-contained application: small, fast and easy to audit.
