English

In one sentence: Clipboard Clear Paste runs entirely on your computer, makes no network connections of any kind, and never stores the contents of your clipboard.

What data the application processes

The application reads the contents of the Windows clipboard at the moment you press one of its keyboard shortcuts, and only then. The content is processed in memory and pasted into the application you are working in. The previous clipboard contents are then restored.

Clipboard contents may include personal data if you happen to copy such data. This is why the processing is described here even though nothing leaves your computer.

What the application does not do

No network accessThe application makes no connections of any kind - not for updates, telemetry, licence checks or anything else.
No clipboard storageClipboard contents are never written to disk, to a log, or to any history.
No telemetryNo usage statistics, crash reports, device identifiers or analytics are collected.
No keyboard monitoringThe application registers three specific key combinations with Windows using the standard RegisterHotKey interface. It installs no keyboard hook and cannot observe any other keystroke.
No accountsNo registration, sign-in or user identification of any kind.
No advertisingNo adverts and no third-party advertising or tracking components.

What is written to disk

One file only - your own settings:

%LOCALAPPDATA%\ClipboardClearPaste\settings.json

It contains the state of the option switches, the selected interface language and your keyboard shortcut definitions. It contains no clipboard content and no personal data. Deleting it restores the factory defaults.

If the application is installed from Microsoft Store, Windows redirects that location into the package's own storage area, and it is removed when you uninstall the application.

Source address feature

The optional Append source address setting adds the web address of the page you copied from underneath the pasted content. That address is read from data your browser itself places on the clipboard. Nothing is requested from the network and nothing is sent anywhere. The option is disabled by default.

Data sharing

No data is shared with anyone, because no data is collected. There are no processors, no sub-processors and no third-party recipients.

Jakie dane program przetwarza

Program odczytuje zawartość schowka systemu Windows w chwili naciśnięcia jednego ze swoich skrótów klawiszowych i wyłącznie wtedy. Treść jest przetwarzana w pamięci operacyjnej i wklejana do aplikacji, w której pracujesz. Poprzednia zawartość schowka zostaje następnie przywrócona.

Zawartość schowka może obejmować dane osobowe, jeśli akurat takie dane skopiujesz. Dlatego przetwarzanie jest tutaj opisane, mimo że nic nie opuszcza Twojego komputera.

Co jest zapisywane na dysku

Wyłącznie jeden plik - Twoje własne ustawienia:

%LOCALAPPDATA%\ClipboardClearPaste\settings.json

Zawiera stan przełączników, wybrany język interfejsu i definicje skrótów klawiszowych. Nie zawiera treści ze schowka ani danych osobowych. Usunięcie go przywraca ustawienia fabryczne.

Przy instalacji z Microsoft Store system Windows przekierowuje tę lokalizację do przestrzeni pakietu, a plik jest usuwany wraz z odinstalowaniem programu.

Funkcja dopisywania źródła

Opcjonalne ustawienie Dopisz adres źródła dokleja pod wklejoną treścią adres strony, z której pochodzi. Adres jest odczytywany z danych, które przeglądarka sama umieszcza w schowku. Nic nie jest pobierane z sieci ani nigdzie wysyłane. Opcja jest domyślnie wyłączona.
